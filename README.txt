Student website for GEOL2331 (Weeks 3-4)
=========================================
Blackboard strips the scripts out of uploaded HTML files, so the interactive labs only work
from a proper web host (this folder) or as SCORM packages inside Blackboard (../blackboard/).

Put this folder online with GitHub Pages (free, public, ~10 minutes, no software needed):
 1. Sign in at https://github.com (create a free account if you don't have one).
 2. Top right "+" -> New repository. Name: geol2331. Public. Create repository.
 3. On the new repository page click "uploading an existing file".
    Drag in ALL the files from this folder (index.html, the four .html files, README.txt).
    Click "Commit changes".
 4. Settings -> Pages -> Build and deployment -> Source: "Deploy from a branch",
    Branch: main, folder: / (root) -> Save.
 5. After a minute or two the site is live at  https://YOUR-USERNAME.github.io/geol2331/
    (the labs are at .../Week3_Soil_Water_Lab.html and .../Week4_Salt_Clay_Current_Lab.html).
 6. Test the links on a phone, then add them to Blackboard Ultra:
    Course Content -> "+" -> Create -> Link (or paste the link into a Document).

To update later: open the repository, "Add file" -> "Upload files", drag in the changed files, commit.
These are standalone copies (full HTML header, UTF-8) of the files one level up.
